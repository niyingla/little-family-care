## 云托管和私有环境变量

本机 `config.local.js` 保存当前环境 ID、服务名和模板 ID；新会话从本机配置与平台页面核对实际值，不能把示例配置当正式配置。平台设置：0.25核/0.5GB，最小0、最大1副本；默认公网/内网访问入口关闭，公网出口开启以访问阿里云。初始化空腾讯数据库及示例服务已删除，正式家庭数据不在腾讯数据库。

| 服务端变量 | 用途与约束 |
|---|---|
| `WX_APP_ID`、`WX_APP_SECRET` | 真实微信登录及消息接口；仅服务端保存 |
| `OWNER_OPENID` | 本人唯一家庭管理员；最后一次 bootstrap 检查尚未配置，正式创建家庭前必须核对本人身份后设置 |
| `DATABASE_DRIVER=mysql` | 选择 MariaDB/MySQL 持久化；云托管不能使用临时 SQLite |
| `MYSQL_CONFIG_BASE64` | 私有连接 JSON，可先 gzip 再 base64，适配环境变量容量限制；编码不是加密 |
| `SIGNING_SECRET` | 私有图片短期签名；随机强密钥，固定保存以便副本一致 |
| `REMIND_TEMPLATE_ID`、`REMIND_FIELDS` | 真实获准微信模板及 task/baby/time 字段映射；不能照抄示例字段冒充可用 |
| `MESSAGE_STAGE` | 体验期 `trial`，正式版按实际阶段修改 |
| `REMINDER_ENABLED=false` | 云托管中关闭常驻扫描，阿里云独立 timer 负责 |
| `BIND_HOST=0.0.0.0`、`PORT=3000` | 容器监听；原自建服务仍只监听回环地址 |
| `PUBLIC_ORIGIN` | 当前云托管使用相对私有图片路径；将来改自有域名才填实际HTTPS来源 |

连接 JSON 仅有 `host/port/serverName/user/password/database/ca/cert/key` 等明确字段；应用账号为专用 `care_app`，不能使用 root。数据库端要求客户端证书，客户端同时验证 CA 与服务端证书主机名。不要因 Navicat 报错关闭校验：客户端私钥、客户端证书、CA证书分别放入正确字段，Cipher 留空，不能将文件路径填入 Cipher。

此前云托管“开放接口服务”的代理替换微信 API 证书，导致 `DEPTH_ZERO_SELF_SIGNED_CERT`；已关闭该代理并重新发布005解决。不能通过 `NODE_TLS_REJECT_UNAUTHORIZED=0` 绕过。

## 数据结构与备份

业务表应使用 InnoDB、utf8mb4_bin：`care_records(collection VARCHAR(64), id VARCHAR(128), body LONGTEXT, PRIMARY KEY(collection,id))`；`care_mutex(id TINYINT PRIMARY KEY)` 必须存在 `id=1` 行。应用账号仅有业务库 SELECT/INSERT/UPDATE，照片墙删除采用受权软删除，不需要给应用数据库管理权限。

逻辑集合包括家庭/成员、按日执行流水、邀请、微信用户/会话、消息队列、无内容行为日志、照片元数据/二进制和照片墙链式分页索引。不要因头像或照片在业务JSON中看不到文件路径，就认为照片没有持久保存。数据库文件必须通过 MariaDB 备份工具或一致性备份导出，不能运行中随意复制整个 `/var/lib/mysql/`。备份和恢复需覆盖记录、图片二进制、私有CA及环境配置；加密、单独保存，不进公开GitHub。

## 上线验收与回滚

- 实际用户身份初始化管理员，创建家庭；只有管理员发邀请卡片，对方接受即加入。没有输入或复制邀请码入口。移除后旧卡不可复用，新卡可重新邀请同一身份。
- 两账号验证未受邀/受邀/被移除访问边界；成员只能删自己的照片动态，管理员可删全部。
- 负责人、提醒人均可留空；空字段不展示。有提醒人才发超时通知。未来具体日期使用“仅一次 + 执行日期 + 执行时间”。
- 公历与农历生日在提前3天北京时间10:00起扫描提醒全体有效家人；闰日/闰月处理按界面说明。实际调度约5分钟，不能承诺秒级准点。
- 完成时可拍照或直接完成，取消和上传失败不能误打勾；撤销保留历史照片；关注者仅在有可用微信订阅额度时收到真实通知。
- 家庭照片墙按时间分页，支持家庭日常和具体宝宝；核对照片发布、查看、筛选及删除权限。
- 原生编译及开发者工具截图不代替手机验收。小程序备案、隐私指引（含生日/照片及日志）、模板用途和审核材料须按当前功能重查，再上传代码提审。

回滚先选上一可用云托管版本并恢复对应提醒代码与锁定依赖；数据库新增JSON字段按兼容读取处理，不能通过删库回滚。原 Nginx/Node 入口仍在，但未经备案/HTTPS/合法域名及真实登录复核，不能把前端直接切回旧域名。
