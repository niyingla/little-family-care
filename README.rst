我家日常小事簿
==============

温暖、简洁的家庭共享待办微信小程序。首版 ``release-0.1.0``，使用原生微信小程序，支持轻量Node.js服务器与微信云开发两种后端。

项目状态
--------

支持微信云托管应用 + 自有服务器MySQL/MariaDB持久数据的混合部署，同时保留 Node.js 24 + SQLite + Nginx 自建模式。业务规则、接口及执行历史共用。混合部署的家庭数据和头像均在自有数据库，提醒由自有服务器独立定时器执行。正式微信登录、消息模板及真机联调需要开发者自己的账号配置。浏览器预览不代表微信真机验证；普通一次性订阅不能承诺一次授权后永久提醒。

功能
----

* **宝宝事项**：多宝宝姓名与头像；选择具体宝宝，单独完成和查看历史。
* **家庭事项**：不关联宝宝，记录家务、采购、办理事项等家庭安排。
* **周期**：仅一次、每天、每隔N天、每周指定星期；统一北京时间。
* **共享执行**：指定执行人，家人共同打勾与撤销；并发版本校验避免覆盖刚完成的记录。
* **重要事项置顶**：两大事项块分别显示；共享置顶状态，不改变周期和执行历史。
* **执行历史**：按日期查看应做、已完成、未完成及执行流水；任务编辑和停用从次日生效。
* **邀请制**：仅预设管理员创建家庭及发送邀请卡片；可选预填家人称呼与家庭身份，受邀者接受后直接入家，无需二次审核。卡片24小时有效且只能接受一次，移除后需重新邀请。不展示邀请码，家庭身份不赋予管理权限。
* **家人列表与生日**：展示称呼、关系和生日；管理员维护全部家人，成员可维护自己。支持公历、农历及闰月，生日前3天北京时间10:00起提醒全体有效家人。2月29日平年按2月28日，农历闰月缺失按普通同月、三十遇小月按月底；日期范围1900至2100年。
* **关注完成**：成员主动关注或取消每项事项，完成后有微信授权额度时通知关注者，执行者本人不重复通知；撤销不抹执行流水。
* **完成照片**：打勾时可选拍照或直接完成；照片随当天完成记录与历史流水留档，只有家庭有效成员可按需查看，照片不进入分享卡片或行为日志。
* **家庭照片墙**：所有有效家人可发布家庭日常或指定宝宝的照片与文字，按时间倒序分页；本人可删自己的动态，管理员可管理全部。宝宝事项完成照片接入同墙，删除墙帖不抹执行证据。
* **执行时间与通知**：负责人、提醒人和时间均可留空，空人员不显示。选定提醒人及时间后，超时30分钟仍未完成才通知；未来具体日期使用“仅一次”。显示真实发送状态，无额度时可手动分享具体任务卡片。

快速运行
--------

要求本地及自建后端 Node.js 24 或以上版本，使用内置SQLite。云函数备选模式的运行时需选择平台实际支持的兼容版本。

::

  npm ci
  npm test
  npm run check
  npm run format:check
  npm run preview

打开 ``http://127.0.0.1:4173``。示例家庭数据只保存在本机；演示模式不发送微信消息、不创建云资源。

自有服务器接入
--------------

将源码放在 ``/opt/little-family-care/current``，安装Node.js 24.15.0到 ``/opt/little-family-care/runtime``；参考 ``deploy/install.sh`` 安装独立系统服务。首次部署会生成私有签名密钥，不会生成假的微信凭据。真实配置保存在服务器 ``/etc/little-family-care.env``，权限600；数据库与头像保存在 ``/var/lib/little-family-care``，不在公开源码目录。

``GET /health`` 用于服务自检；``POST /api/login`` 使用wx.login返回的code换取服务器会话，``POST /api/call`` 使用会话调用家庭业务。头像以10分钟签名URL访问。请先配置微信AppID和AppSecret、唯一管理员OpenID及真实消息模板；这些值不提交Git。

前端在本地 ``config.local.js`` 填写 ``apiBaseUrl`` 的HTTPS域名。域名解析到服务器后安装Certbot，运行 ``sudo bash deploy/configure-https.sh api.example.com`` 申请免费证书并配置HTTPS。脚本先备份配置，失败时回退；成功后启用每天检查两次的续期定时器，证书续期成功才重载Nginx。Node进程只监听127.0.0.1:3000，外部经Nginx的443端口访问，80端口保留证书挑战及HTTPS跳转。

域名、证书、微信凭据与合法域名配置完成并通过真机验证后，才表示正式小程序已接通。证书续期可用 ``sudo certbot renew --dry-run`` 验证；私钥只保留服务器，不进入源码。

微信云托管与自有数据库
--------------------

根目录Dockerfile用于微信云托管，监听3000端口。运行环境注入 ``DATABASE_DRIVER=mysql``、``MYSQL_CONFIG_BASE64`` 以及现有微信配置，关闭容器内扫描 ``REMINDER_ENABLED=false``。MySQL配置包含专用账号、口令、``host``、``serverName``、``database`` 和双向TLS的 ``ca/cert/key``；JSON可先gzip压缩再base64编码，以适配平台环境变量5KB限制，同时兼容旧版原始JSON的base64格式。压缩和编码都不提供加密，配置仍属服务端秘密，不得写入Dockerfile、代码包或日志。数据库证书必须验证受信任CA和服务端主机名，服务端应用账号须强制验证客户端证书；不开通腾讯MySQL承载家庭数据。

业务库须事先创建 ``care_records(collection VARCHAR(64), id VARCHAR(128), body LONGTEXT, PRIMARY KEY(collection,id))`` 和 ``care_mutex(id TINYINT PRIMARY KEY)``，均使用InnoDB，字符集utf8mb4、排序规则utf8mb4_bin，并向互斥表插入唯一行 ``id=1``。应用账号只授予业务库SELECT、INSERT、UPDATE权限。多个应用副本和提醒进程通过互斥行共享事务边界；不能删掉互斥行或关闭TLS校验来解决连接错误。

配置 ``deploy/little-family-care-reminder.service`` 与 ``.timer``，每5分钟运行独立扫描；环境文件权限600。云托管休眠不影响阿里云定时器。头像按512KiB分段下载到小程序私有沙盒，适配云托管1000KiB响应限制。基础库应使用2.23.0及以上版本，小程序用 ``cloudRunEnvId``、``cloudRunService`` 配置通过 ``wx.cloud.callContainer`` 访问，不要求自有后端域名；正式小程序备案和审核仍须完成。

将来接入自有域名时，完成备案、HTTPS和微信合法域名配置，在服务端设置 ``PUBLIC_ORIGIN``，客户端清空两项云托管配置并填写 ``apiBaseUrl``，保持业务接口与原有数据即可。若应用迁回自有服务器，复用同一运行入口和MySQL持久数据，不必重写家庭业务。

微信云开发备选接入
------------------

1. 注册微信小程序、完成类目及必要备案，导入项目时选择自己的 AppID。
2. 使用微信云开发的文档型数据库，绑定同一小程序与腾讯云账号。
3. 将 ``miniprogram/config.local.example.js`` 复制为 ``config.local.js``，填写环境和模板ID；真实配置被 Git 忽略。
4. 按 ``cloud-settings.example.json`` 创建集合，将客户端数据库和存储权限均设为禁止直读直写。
5. 云端安装依赖并部署 ``family``；配置唯一管理员 ``OWNER_OPENID``，只有此人能初始化家庭。
6. 配置实际可用的订阅消息模板与字段，然后部署 ``reminder`` 及每5分钟的定时触发器。
7. 两个微信账号分别验证卡片直接入家、移除、访问、执行、照片和消息后，再进行提审与发布。

服务器实际目录、Nginx、数据库、代码库、混合部署更新、检查与回滚见 `部署说明 <docs/部署说明.md>`_；早期云开发向导见 `setup.html <setup.html>`_。配置示例中的模板字段是假设，必须替换为实际获准模板，不得直接宣称通知可用。

目录与维护
----------

::

  miniprogram/pages/index/controllers/  时间线、任务、家庭、邀请、生日、关注及照片交互
  miniprogram/pages/index/templates/    各区域与表单WXML
  miniprogram/utils/domain.js           周期、权限、历史、置顶规则唯一来源
  server/service.cjs                   服务端事务、邀请和通知队列
  server/birthdays.cjs                 公农历换算及生日提醒候选
  server/cloud.cjs                     微信云数据库和消息接口适配
  selfhost/                           HTTP、微信登录、SQLite/MySQL与私有头像、独立提醒
  deploy/                             自建服务器配置、systemd与独立Nginx
  cloudfunctions/family/               家庭业务与私有头像上传入口
  cloudfunctions/reminder/             独立定时任务入口
  tests/                              业务规则、权限、并发和表单回归测试
  preview/                            复用实际页面控制器的浏览器预览桥
  scripts/                            准备、格式检查、结构检查和预览
  assets/                             原创应用图标

``server/domain.js`` 和两个云函数的 ``lib/`` 是构建复制结果。修改共用规则或服务端实现后运行 ``npm run prepare``，不要直接修改生成副本。小程序客户端不直连数据库；自建模式通过HTTPS访问业务入口，云开发模式通过云函数访问。

开发规范
--------

职责单一、重要业务方法补齐参数说明、中文注释说明业务边界；日志记录操作、数量与耗时，不打印微信身份、邀请码、图片内容或密钥。提交前运行测试、结构和格式检查；提交说明携带实际发布版本。不要提交真实宝宝信息、头像、OpenID、云配置或个人IDE配置。

已知边界
--------

家庭上限20名有效成员、10位宝宝、200项任务。头像及每次完成的单张照片限1MB内JPG或PNG；当前仅支持当天打勾，历史不支持补签。暂不提供家庭删除、宝宝删除、成员权限细分、每月重复或离线真实数据编辑。定时检查约5分钟，生日在指定日10:00起的扫描发送，不能承诺秒级准点。任务、生日及关注完成通知均受微信订阅授权额度限制，发送成功只代表微信接口接收，不代表对方已读。未知发送结果不盲目重发，需要结合日志处理。
